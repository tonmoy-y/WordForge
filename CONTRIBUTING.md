# Contributing to WordForge

Thank you for your interest in contributing to **WordForge**! We welcome bug reports, feature proposals, document format test cases, and pull requests.

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tonmoy-y/WordForge.git
   cd WordForge
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Run the test suite:**
   ```bash
   npm test
   ```

5. **Build production bundles:**
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Ensure all existing tests pass (`npm test`).
- Add tests for new features, document parser behaviors, or regression fixes.
- Follow TypeScript strict typing conventions.
- Keep commits clear, focused, and well-described.
